######################### Topic 4 — Bitwise operators #########################
Bitwise operators work on the individual bits of integer values. For example, decimal 5 is binary 0101, and decimal 3 is binary 0011 when shown using four bits.

For this section, focus on the calculation, not memorizing answers.

B1. Bitwise AND (&)
Store 5 and 3 in integer variables. Print a & b.

B2. Bitwise OR (|)
Using the same values, print a | b.

B3. Bitwise XOR (^)
Store 6 and 3. Print a ^ b.

B4. Left shift (<<)
Store 4 in an integer variable. Print a << 1. If left shift hasn't been taught yet, leave this one until class covers it.


B5. Compare AND and OR
For a = 10 and b = 12, print a & b and a | b. Explain why the results differ.

B6. XOR with equal values
Store 7 in both a and b. Print a ^ b.

B7. Complement (~)
Store 5 in an integer variable. Print ~a. Try to explain the result using Java's signed integer representation.

B8. Right shift (>>)
Store 20 in an integer variable. Print a >> 2.


B9. All three bitwise operators
For a = 13 and b = 10, print a & b, a | b, and a ^ b. Work out the binary values first.

B10. Multiple shifts
Store 12 in an integer variable. Print a << 2 and a >> 1.

B11. Bitwise expression
For a = 6, b = 3, and c = 5, calculate:
a & b | c
Predict the result using Java's operator precedence, then run it.

B12. XOR sequence
Start with a = 9, b = 5, and c = 3. Print:
a ^ b, b ^ c, and a ^ b ^ c.
Show the binary working for the last expression.

B13. Mixed bitwise operations
For a = 12 and b = 10, calculate:
a ^ b & a | b
Predict the output using Java's operator precedence. Then verify it.

B14. Complement and AND
For a = 10 and b = 7, calculate:
(~a) & b
Explain why the result is not obtained by treating ~a as a four-bit-only complement.

B15. Shift and mask
Store a = 45. Calculate:
(a >> 2) & 7
Work out each intermediate result.

B16. Signed versus unsigned right shift
Store a = -16. Print a >> 2 and a >>> 2. Compare the outputs and explain the difference between sign extension and zero filling.


Note: Questions B14–B16 are intentionally more advanced. If your teacher has only covered &, |, and ^, complete B1–B3 first and return to the rest as those operators are taught.




######################### Topic 5 — Data types and literals #########################
This section tests whether you understand the type of a value, which values can be stored in a variable, and what happens when Java converts between types.

Remember:
- byte, short, int, and long store whole numbers.
- float and double store floating-point numbers.
- char stores a single UTF-16 code unit, written using single quotes for character literals.
- boolean stores true or false.



D1. Choose the data type
Identify the most suitable primitive type for each value: 25, true, 4.5, 'A', and 9000000000L.

D2. Declare variables
Declare one variable each of type byte, short, int, long, float, double, char, and boolean. Give each a valid example value.

D3. Integer literals
Declare an int variable with value 250 and a long variable with value 5000000000L. Print both.

D4. Floating-point literals
Declare a float variable with value 3.14f and a double variable with value 3.14. Print both.


D5. Primitive ranges
Identify which primitive integer type is suitable for each value: 100, 30000, 200000, and 5000000000L. Choose the smallest suitable type from byte, short, int, and long.

D6. Find the compilation problem
Examine these declarations one at a time. Which are valid, and which produce compilation errors? Explain why.
int a = 10;
long b = 5000000000L;
float c = 3.14f;
float d = 3.14;
char e = 'A';
char f = "A";


D7. Character arithmetic
Declare char ch = 'A';. Print ch and then print ch + 1. Observe the difference between the outputs.

D8. Boolean values
Declare two boolean variables, one true and one false. Print each value and the result of comparing them using == and !=.


D9. Type conversion
Store 25 in an int variable. Assign it to a long variable and print both values. Explain why this assignment is permitted.

D10. Narrowing conversion
Store 130 in an int variable. Try assigning it to a byte variable. Observe the compilation result. Then investigate how an explicit cast changes the result.

D11. Floating-point calculation
Declare float a = 5.5f and float b = 2.0f. Print their sum, difference, product, and quotient.

D12. Integer overflow
Store 127 in a byte variable. Try to calculate a + 1 and assign the result to another byte variable. Does the code compile? If not, investigate why, and test an explicit cast.


D13. Find the smallest suitable type
For each value below, identify the smallest suitable primitive type from byte, short, int, and long:
-128, 127, 128, 32767, 32768, and 2147483648L.
Explain the boundaries.

D14. Trace mixed arithmetic
Examine the following program and predict whether it compiles. If it compiles, predict the output.

double b = 2;
double c = a / b;
System.out.println(c);
Now change b to an int variable with value 2. Predict the new output and explain the difference.

D15. Character and integer types
Declare char ch = 'A';. Store ch + 2 in an int variable and print it. Then explicitly cast that result back to char and print it. Explain both outputs.

D16. Precision challenge :
Declare two double variables with values 0.1 and 0.2. Print their sum and compare it with 0.3 using ==. Observe the output and investigate why floating-point calculations may not produce the exact decimal value you expect.
