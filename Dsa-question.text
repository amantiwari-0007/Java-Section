######################### Topic 4 — Bitwise operators #########################

For this section, focus on the calculation, not memorizing answers.

######################### Topic 5 — Data types and literals #########################

This section tests whether you understand the type of a value, which values can be stored in a variable, and what happens when Java converts between types.

Remember:
- byte, short, int, and long store whole numbers.
- float and double store floating-point numbers.
- char stores a single UTF-16 code unit, written using single quotes for character literals.
- boolean stores true or false.
