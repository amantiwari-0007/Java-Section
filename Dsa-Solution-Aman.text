 To reverse a number properly using arithmetic operators, you need a formula that works for any two-digit number.

The Math Behind Reversing a Number

To reverse a two-digit number like 68 into 86, you need to separate its digits using division (/) and modulo (%):
1. Find the last digit (ones place): 68 % 10 = 8
2. Find the first digit (tens place): 68 / 10 = 6
3. Combine them in reverse order: Multiply the new first digit by 10 and add the second digit: (8 * 10) + 6 = 86


public class Main {
    public static void main(String[] args) {
        int number  = 68;
        int FirstNumber = 68/10;
        int LastNumber = 68%10;
        // 3. Shift the last digit to the tens place and add the first digit
        System.out.println(LastNumber *10 +FirstNumber);
    }
}

public class Main {
    public static void main(String[] args) {
        int totalSeconds = 10537;
        
        // 1. Calculate complete hours
        int hours = totalSeconds / 3600; 
        // 2. Find leftover seconds after removing complete hours
        int remainingSecondsAfterHours = totalSeconds % 3600;
        // 3. Calculate remaining minutes from the leftover seconds
        int minutes = remainingSecondsAfterHours / 60;
        // 4. Calculate the final remaining seconds
        int seconds = remainingSecondsAfterHours % 60;

        System.out.println("Hours: " + hours);     // Outputs 2
        System.out.println("Minutes: " + minutes); // Outputs 55
        System.out.println("Seconds: " + seconds); // Outputs 37
    }
}
